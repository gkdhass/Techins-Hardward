  When Root Directory = client

  Vercel is already INSIDE the client folder.

  So commands run from: /client/

  ❌ Build Command: "cd client && npm run build"
     Tries to: /client/cd client/
     Result: ERROR - No such file or directory

  ✅ Build Command: "npm run build"
     Runs from: /client/
     Result: SUCCESS - Builds correctly
