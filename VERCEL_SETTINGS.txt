│ TROUBLESHOOTING                                         │

Build fails?
→ Check Root Directory is blank (repository root)
→ Verify all environment variables are set
→ Check build logs in Vercel dashboard

API returns 404?
→ Verify api/index.js exists in root
→ Check vercel.json is in root
→ Redeploy

CORS errors?
→ Update CLIENT_URL to exact Vercel URL
→ Include https://, no trailing slash
→ Redeploy

MongoDB errors?
→ Check MONGODB_URI is correct
→ Verify 0.0.0.0/0 whitelisted in Atlas
→ Test connection locally

File upload fails?
→ Verify all 3 Cloudinary variables
→ Check API Secret is correct
→ Check Cloudinary account is active
