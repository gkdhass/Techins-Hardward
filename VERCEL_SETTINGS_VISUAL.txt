║  ❌ COMMON MISTAKES (DON'T DO THESE!)                               ║
║                                                                       ║
╚═══════════════════════════════════════════════════════════════════════╝

  ❌ Mistake 1:
     Root Directory: server
     Result: Can't find client/ folder, build fails

  ❌ Mistake 2:
     Root Directory: client
     Result: No backend API, frontend works but API calls fail

  ❌ Mistake 3:
     Build Command: cd client && npm install && npm run build
     Result: If Root is "server", can't find client/ folder

  ❌ Mistake 4:
     Framework Preset: Express
     Result: Wrong build configuration for monorepo

  Your Repository Structure:
  
  techins-hardware/  ← ROOT (Vercel starts here)
  ├── api/
  │   └── index.js         ← Serverless function (backend)
  ├── client/
  │   ├── src/             ← React app
  │   ├── dist/            ← Built here (client/dist)
  │   └── package.json
  ├── server/
  │   ├── server.js        ← Express app (used by api/index.js)
  │   ├── routes/
  │   └── controllers/
  ├── vercel.json          ← Routing config
  └── package.json         ← Root package (has npm run build)

  What Vercel Does:
  
  1. Starts at ROOT (/)
  2. Runs: npm run build
  3. Builds: client/ → client/dist
  4. Deploys: api/index.js as serverless function
  5. Serves: client/dist as static site
